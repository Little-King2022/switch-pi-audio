# Bundled SBC decoder

The files in `upstream/` are the decoder from Android's Bluetooth module at commit `745ee92b87ed62b5a8a1bac47d5df8cad623bf59`. Copyright belongs to the holders named in the individual files, including the Android Open Source Project and Open Interface North America.

- [Pinned upstream source archive](https://android.googlesource.com/platform/packages/modules/Bluetooth/+archive/745ee92b87ed62b5a8a1bac47d5df8cad623bf59/system/embdrv/sbc.tar.gz)
- [Upstream license notice](NOTICE)

`SBCDecoder.c` and `SBCDecoder.h` are the project's wrapper for 48 kHz stereo and joint-stereo SBC.
